# HousePlanner

HousePlanner е самостоятелно web приложение за планиране на имот, ремонт и материали.

## Основни функции

- План на имота с помещения и автоматично изчисляване на площ/периметър
- Схема на стени с врати, прозорци и други отвори
- Нетна квадратура на стена след изваждане на отворите
- Калкулатор за подова площ с резерв/фира
- Калкулатор за боя според площ, покривност, брой ръце и резерв
- Списък с материали и готови шаблони за боядисване, ламинат, шпакловка и гипсокартон
- Бюджет за материали и допълнителни разходи
- Локално запазване на проекта чрез `localStorage`
- PDF export с обобщение на помещения, стени, настилки, материали и бюджет
- Responsive интерфейс за desktop и mobile

## Стартиране

Не е необходим build процес. Отвори `index.html` директно или стартирай локален HTTP server:

```bash
python -m http.server 8080
```

След това отвори `http://localhost:8080`.

## PDF export

PDF export използва jsPDF и jsPDF AutoTable през CDN, затова за тази функция е необходима интернет връзка. Самото приложение и запазените данни работят локално в браузъра.

## Следващи подходящи подобрения

- Drag & drop редактор на реален 2D план
- Неправоъгълни помещения и многоъгълници
- Обекти за мебели, контакти, ключове, радиатори и санитария
- Изчисляване на плочки, тапети, гипсокартон, мазилка и замазка

- Импорт/export на проект като JSON
- PWA/offline режим
